## [0.0.1-beta.7] - 2026-11-12

### 新增

- **更新重启随监管形态路由** —— 自更新换包后的重启按监管形态分流：Windows
  服务交还 SCM（`sc.exe start`）、macOS launchd 形态交 KeepAlive 拉起、
  bare/前台形态带**原命令行参数**重拉（此前 `--host`/`--data-dir` 等旗标在
  更新后静默丢失）；新进程脱离控制台（关窗不再连带杀掉），输出落数据目录
  日志文件并注记「已转后台守护」，回滚链同走形态路由。
- **会话自动命名** —— 智能体终端会话按首条用户消息自动总结命名（约 40 字符
  内）；手动改名永远优先；设置开关可关（热切换）。
- **终端会话分组** —— 自定义分组补折叠 chevron+会话计数徽标（与项目分组
  同款）；拖拽整区落点（组段任意空白可承接，两承接面均可排序）；runtime
  视图隐藏分组时侧栏显示弱提示行。智能体可经 ops API 管理分组
  （建组/重命名/排序/删除、移入移出会话），变更广播到所有打开的界面。
- **自更新面板渲染发布说明** —— 应用内更新面板把 Release 说明按净化
  markdown 渲染并支持展开/收起，附「查看发布页」外链。
- **`frontend.reload` agent 原语** —— 智能体可驱动前端整页/当前视图重载
  （批量修改后对账用），受与其他前端原语同款的逐原子设置门控。
- **dsh 0.2.2-rc.1 已知缺陷标注** —— 版本弹窗对该已知缺陷版本显示警示块并
  引导升级 rc.2+。

### 变更

- **双语发布说明锚点化** —— GitHub Release 页改为顶部一行语言切换
  （[English] | [中文]）+ 中/英各自带锚小节（英文在前），取代原折叠形态；
  切换行、双语小节及其顺序在装配时点断言硬闸——模板回归直接 FATAL 停步
  不发布，而非静默上线。
- **更新重启排障文档** —— README 与 Linux 部署指南补齐各监管形态在自更新
  前后的行为差异（systemd、Windows 服务含短暂 STOPPED 窗口、launchd、
  bare/后台守护），含日志位置与回滚说明。
- **访客分享页状态条** —— 快照/过期双行提示合并为单行紧凑状态条（完整
  长句保留在悬停 title）。

### 修复

- **笔记无扰处理外部更新** —— 本窗保存不再回声为外部更新（窗口级 origin
  nonce）；异窗修改换装不再卸载编辑器（光标与选区跨换装锚定；内容一致零
  触碰）；409 冲突条在真实保存链路真正可现（此前因错误形态不匹配从未
  挂出过）。
- **分隔条不再抢文本选区** —— 调宽把手只响应侧栏一侧；远程主机列表默认宽
  提升至 320 px（下限 220），存量记忆宽度不受影响。

## [0.0.1-beta.6] - 2026-11-11

### 新增

- **自更新下载断点续传** —— 大体积更新下载保留 `.part` 文件，重试从字节偏移
  续传；拼接安全用强 ETag If-Range/206 身份核对强制保障（远端内容被换即拒绝
  并清除，绝不拼进你的安装包）；200/416 响应回退干净的全量下载；换包只在
  完整性闸通过后执行（原子改名）。
- **自动重试收编进续传链** —— 瞬时下载失败自动退避重试并从偏移续传（进度
  不回零）；403/404 等确定性失败不空耗尝试；残留临时文件 7 天后清理；
  失败卡片新增「重试更新」一键。
- **续传进度看得见** —— 下载中态显示「已续传 xx MB」（新增 `resumedBytes`
  字段），弱网长更新如实呈现而非从 0% 重新计数。
- **系统代理探测接入选路** —— 更新出站选路升级四档：显式设置 > 环境变量 >
  系统代理自动探测（默认关；Windows 读注册表、macOS 读 `scutil`、GNOME 读
  `gsettings`）> 直连。探测档尊重 NO_PROXY；一切代理路径仍受官方域白名单
  守卫；版本面板展示当前生效档位，背后是新的 proxy-status 诊断端点
  （地址脱敏、按需即时刷新）。

### 变更

- **更新代理文档补齐** —— README 新增双语更新代理节（四档、NO_PROXY 立场、
  探测时机）；Linux 部署指南补 systemd `HTTPS_PROXY`/`NO_PROXY` 示例与
  daemon-reload 说明；升级判别表补 Windows 服务行与「重跑安装器为何安全」。

## [0.0.1-beta.5] - 2026-11-10

### 新增

- **更新可走代理** —— 新增更新代理设置，三态出站选路（直连/代理/自动），自更新
  流量可经 HTTP(S) 代理；代理路径带官方域白名单守卫，更新链不会被指向任意主机。
- **更新进度离开可见** —— 自更新改异步受理、服务端上报生命周期：全局进度徽标
  阶段化透出（下载→校验→换包→重启），离开版本面板也能盯着更新；失败以通知
  呈现，不再静默死掉。
- **终端选中复制链路硬化** —— OSC 52 剪贴板交接在各终端面统一并配合 tmux
  `set-clipboard on`；tmux 版本地板两档提示；剪贴板写失败兜底浮条；新增 tmux
  鼠标接管开关（默认开、热切换、复制优先一键直达）——拖选复制与滚轮在各种
  TUI 应用与较旧 tmux 上都不再打架。
- **一键安装参数上文档** —— README 与官网补一行式安装参数样例；
  `CODECOMBO_DATA_DIR` 服务化安装全程贯通。

### 变更

- **`codecombo update` 服务停止时不再换包** —— 无验签直换包的离线更新路径
  因供应链安全退役；命令改为打印指引：先起服务走应用内验签自更新（带自动
  回滚），或用包管理器（npm 安装指向 `npm i -g codecombo@latest`）。服务
  运行中时 `codecombo update` 行为不变（同一条验签+自动回滚链）。
- **「已是最新」看得见了** —— 检查成功态显著化+检查中态；「是否最新」判断
  统一，通知面板与版本面板不再各说各话。
- **升级已装实例指引补强** —— README 新增装法判别表、路径分级与常见
  `203/EXEC` systemd 失败的诊断。

### 修复

- **Windows 后台启动关窗不死** —— `codecombo start` 守护进程脱离控制台
  （此前关掉启动窗口守护即被终止）；安装器诊断行跑真前台 `--serve`；
  「前台/后台」措辞统一。
- **脚本装实例自更新重启可用** —— install.sh 补装远程部署器同款 polkit
  放行规则，更新后的 `systemctl restart codecombo` 获得授权，不再静默
  把服务留在停机态。
- **Windows 安装器覆盖序修复** —— 停服先行于二进制覆盖；预检前置 fail-fast
  （不覆盖任何文件才报错）；覆盖失败回滚。
- **6h 自动检查真正听开关** —— 关闭「自动检查更新」现在真的停掉前端定时器
  （热切换三路），而非只静默服务端检查。
- **更新伴随资产拉取失败透出** —— 签名/哈希伴随资产下载失败三态区分、
  有限重试+绕缓存重拉、检查时旗标化，不再拖到安装时才暴露。
- **页面重启支持 LAN** —— Web 界面重启应用现在接受 LAN 连接携带的有效锁
  token（此前仅回环），双路授权。
- **安装脚本下载断点续传** —— install.sh / install.ps1 主包下载加 curl
  `-C -` 配合既有重试，断连从断点续传 ~50MB 主包而非从头再来。

- **会话管理打磨** —— 右键菜单补齐与底部终端同款的分享/导出四件与直播徽标；
  回首页=纯首页（会话管理不再跟随），进入项目则恢复该项目此前的布局。

## [0.0.1-beta.3] - 2026-11-06

### 修复

- **检查更新此前从未真正工作** —— 内置官方源是 github.com 网页地址，而取数
  端点全按 REST API 路径拼接；缺一步 URL 归一使每次检查都在把网页 HTML 当
  JSON 解码而失败，最终呈现为误导性的「未配置更新分发源」提示。网页仓库地址
  现归一到 api.github.com；检查失败不再一律吞成「已是最新」：stable 通道暂无
  正式版时如实说明并指向「跟进预发布版本」开关，其余失败（网络/非法源）
  如实呈现原因（beta.1/beta.2 回归）。
- **Windows 服务数据目录** —— 服务命令行直传 `--data-dir`，把数据目录钉到
  安装者用户目录（`%USERPROFILE%\.codecombo`）：此前经服务环境变量注入在
  LocalSystem 下静默不生效，服务会以空数据目录启动而非复用既有数据。
- **远程部署存量升级** —— 老版本迁移不再 `install binary exit 1`：二进制
  直接装入 ExecStart 最终路径（legacy 目录随首启迁移整体改名），消除装入
  目录与迁移目标之间的鸡生蛋死锁；安装失败时远端命令 stderr 原文进任务日志。
- **Windows 短路径归一** —— 缺失目标尾段的短名（8.3）成分一致解析；祖先
  解析曾丢失最后一段路径，边界场景误判 traversal。
- **最近裁决浮层** —— 最近审批浮层支持手动关闭（✕），且只回看 48 小时内
  的裁决，不再永久遮挡终端面板。

### 变更

- **更新相关设置即时生效** —— 「跟进预发布版本」开关、更新源变更与自动检查
  开关保存即生效，不再要求重启。版本面板新增「重启应用」按钮兜底真正需要
  重启的少数设置：Windows 服务走 SCM failure-recovery 拉起，systemd 走
  `systemctl restart`，前台实例以原参数自拉起。
- **npm 平台包改名** —— `codecombo-win32-*` 更名 `codecombo-windows-*`
  （npm spam 风控对 win32 命名加权拦截；darwin/linux 同构包未受影响）。
  `os: win32` 字段保留（npm 官方平台标识），`npm i -g codecombo` 的平台
  选择行为不变。
- **npm 发布流程** —— 主包最先发布，单包失败不再中断其余包；失败包收集
  汇总呈现。

  https://wtr20211202.github.io/codecombo/
