## v0.0.1-beta.11 诊断包 v2 与粘贴上限可配置

- **诊断包 v2**：请求时间线/慢请求、卡顿看门狗（区分进程阻塞与宿主挂起）、错误按签名分组、宿主/TLS/网络取证，每个探针结果如实写入 collection-report
- **深度诊断**：勾选「深度诊断（约 30s）」追加 pprof 档案（heap/goroutine/block/mutex，可选 CPU）；CLI 用 `codecombo diagnostics --out diag.zip --deep`
- **性能证据**：Go 运行时/GC 趋势、三平台进程自观测（Windows/mac 不再跳过）、24h 路由热点表 routes.json
- **浏览器侧诊断**：新增「导出浏览器诊断」（本地 JSON）；「导出诊断包」自动附带最新浏览器快照，一个 zip 两面证据
- **粘贴上传提额**：本机终端文件 20MB→100MB、图片 10MB→20MB；设置→终端「粘贴上传上限」可调（本机最高 512MB），超限错误给出可读上限
- **视觉特效减弱档**：设置→外观「视觉特效：标准/减弱」，远程控制/屏幕共享/低配机建议开启，按设备生效；`?__lowfx=1` 免进设置
- **分享终端宽矮窗口**：页头「完整显示 / 放大」开关，缺省自动；超尺寸视图滚到顶继续上滚可读历史（「回到实时」退出）
- 修复：分享终端滚动再治理、分享创建弹窗撑满整屏、粘贴上限六个输入框 0 宽、「恢复默认」被钳成 1MB、远程终端上传缺请求体上限

## v0.0.1-beta.10 诊断包与远程协助强化

- **一站式诊断包**：设置→系统监控→服务日志「导出诊断包」，日志/更新链/崩溃转储/平台采样打成一个 zip；服务起不来时 `codecombo diagnostics --out diag.zip` 离线采集
- **平台深度采样**：launchctl / systemctl / journalctl / ss / netstat / 进程树，包内 manifest 逐条如实标注存在性
- **可写分享粘贴上传**：访客持权时粘贴图片/文件与主人端一致（压缩→上传→路径入输入行）；观看侧加链接识别、终端内查找、选区复制、WebGL 降级
- **分享终端滚动不闪**：单一滚动面，读历史不再被新输出拽回底部；超尺寸视图滚轮滚页面（全屏应用自己的滚动键仍可用）
- **聚焦终端 Ctrl/Cmd+V 恢复原生粘贴**：文件/图片进上传链，纯文本正常粘贴，不再向主机发字面 ^V
- **访客粘贴不再没反应**：申请中/未持权/已撤销等原因逐一提示
- **可写分享断线自动重连**：退避重连+状态探测，原地恢复不刷新；关闭/过期/撤销直达终态
- **键盘控制权必定归还**：撤销/轮换/过期后输入闸必释放，主人不再被锁在自己的终端外
- **launchd 在线更新可用了**：≤beta.9 的 launchd 实例重跑一次安装脚本即恢复（远程部署实例由中心实例重新部署）；beta.10 起应用内更新正常落地
- **自更新失败有据可查**：换包子进程日志/退出码落盘、crash.log、`CC_LOG_LEVEL`，面板明示「仍是旧版本 vX」并给手动下载链接
- **npm 装实例设置页重启不再坏**：wrapper 循环监管+退出码握手，重启与真崩溃可区分
- **静默失败补留痕**：后端 15 处吞错补日志、前端静默分类修复、订阅者 panic 带堆栈
- 其他：五类分享页拖入文件不再跳转、协作收件箱零误收、窄窗口头部布局、访问提示统一 https、默认四端口文档、访客交付常驻上传按钮
