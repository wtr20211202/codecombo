## v0.0.1-beta.3 存量升级与服务数据目录修复

- **检查更新真正可用了**：内置官方源地址归一修复（此前每次检查都在解码网页 HTML 而恒败）——检查失败也如实分类呈现，stable 通道只有 beta 时会提示开启预发布通道跟进

- **npm 平台包改名**：win32 → windows（npm spam 风控加权），`npm i -g codecombo` 平台自动选择行为不变
- **最近裁决浮层可关闭**：✕ 手动收起 + 48 小时回看窗，不再永久遮挡终端面板
- Windows 短路径（8.3）尾段归一边界修复
