# 智能体会话编排（AGENT SESSIONS）

> 面向使用者的子系统说明：AI 编码智能体如何在 Codecombo 里运行、被编排、
> 被管住。扩展接入面见 [EXTENSION_POINTS.md](EXTENSION_POINTS.md) 的
> agentops.Provider 节；可编程事件契约见 [OPS_EVENTS.md](OPS_EVENTS.md)。

## 1. 运行时接入

- 内置 claude / codex / dsh 三类运行时的一键接入：选择运行时、工作目录与
  初始指令即可创建会话；运行时身份以品牌图标标注在会话上（仅作运行时识别，
  不作产品标识）。
- 会话本体是真实 PTY（与终端子系统同源）：断线重连、页面刷新后完整回放
  scrollback、tmux 持久化（Unix）等终端能力对智能体会话全部适用。
- 自定义运行时经 `agentops.Provider` 扩展点注册（命令模板、会话参数、
  审批解析策略），无需改动核心。

## 2. 会话身份

多会话并行时的「这是谁、是新是旧」闭环：

- **派生名与同名消歧**：会话名可从初始指令首行派生；与存量会话同名时自动
  步进「·2 / ·3」消歧。系统创建链（定时任务/接续链/舰队/运行书）显式命名
  走同一消歧口径；用户手输名尊重原意不去重。
- **重名提示**：手动改名命中重名时返回同名会话摘要（不阻断，显示名允许重名）。
- **「新 / 接续」徽标**：会话元数据标注「系统派生名」「以恢复旗标创建」，
  侧栏行内以短格式时间与徽标区分——新建与复用在界面上有明确承诺。
- **命名注记注入**：带初始指令创建会话时可自动在指令尾部附一行系统注记
  （会话 id + 改名建议 + 查重提醒），可在设置中关闭。

## 3. 审批中心（有刹车的自主）

- 智能体可连续自主工作；命中高危表的动作（高危命令、批量文件替换、迁移
  应用、批量写对端实例等）以**审批卡**回流：逐项放行 / 拒绝 / 改写。
- **过程录制与回放**：审批卡可打开「过程实况」——终端输出按时间轴录制
  （录制默认关闭，隐私边界在设置中显式开启），回放器支持倍速与章节跳转。
- **出域脱敏**：审批内容出域前对 sc 系令牌、`password=` 赋值、云 AccessKey
  等形态统一遮蔽。

## 4. 编排原语

- **接续链**：把工作从会话 A 交接给会话 B（上一棒的产出作为下一棒的输入），
  链健康（存活/棒数/冷却）在值班大屏可见。
- **定时任务**：按 cron 语义定期拉起智能体会话（每日 HH:MM + 周几 + 时区 +
  错过补偿），任务历史可查。
- **运行书**：多步命令序列预存复用——逐步「发送」由人按回车，或全书/舰队
  执行（单会话逐步等退出码；舰队按「步骤 × 目标」矩阵聚合多台会话结果）。
  终端过程录制可一键转草稿运行书。
- **双智能体对比**：同一任务并行发给两个运行时，两块会话并排对比产出。
- **广播写入**：向多个会话同时注入同一段输入（编排场景的原始原语，高危
  面受审批表管辖）。

## 5. 终端协作便利面

- **粘贴图片直传**：截图直接粘贴进终端，自动落临时文件并把路径粘入命令行
  （适配智能体读取本地图文件的常见约定）。
- **定向消息与已读**：会话之间可留言（带已读回执），值班大屏聚合展示
  「谁 → 谁」的协作流。
- **静默检测与停滞分诊**：长时间无输出的运行中会话亮弱标；确认停滞的会话
  可从分诊卡直接「催一下」/ 打开 / 终止。
- **输出检索与书签**：全端输出检索（跨会话）、行级书签、命令块与运行态标记
  （基于终端 shell 集成的命令边界帧）。

## 6. 安全边界速览

- 高危动作审批表覆盖：命令面 / 文件批量面 / 迁移应用 / 同步推送 / 广播写入。
- 智能体没有交互式 sudo 的免密通道；凭据加密存储且审计出域脱敏。
- 定时任务与自动链的载荷不含密钥（构造性排除，测试红线钉死）。

## 7. 手册注入面（各运行时）

| 运行时 | 注入方式 |
|---|---|
| claude | **自动**——服务启动时安装到 `~/.claude/skills/codecombo-ops/`（SKILL.md + references 渐进披露），并在 `~/.claude/CLAUDE.md` 写入常驻标记块兜底 |
| codex | **自动**——启动时写入 `~/.codex/AGENTS.md` 标记块（保留用户自有内容） |
| dsh | **不自动注入**（dsh 无全局指令注入入口；`CC_BASE_URL` / `CC_LOCK_TOKEN` 环境变量已注入，能力可用）——手动方案见下 |
| 其他（gemini 等） | 手动方案同 dsh |

**手动注入方案**：从实例拉取手册全文，粘贴到该运行时的自定义指令 / 系统提示配置：

```bash
curl http://<host>:<port>/api/ops-manual -o codecombo-ops.md
```

（端点免 token；`CC_BASE_URL` 指向本实例时智能体也可自行拉取。）
